# Варіант 7 — Агент фітнес-тренера

## Завдання

Створити AI-агента за допомогою Google ADK.

Агент виконує:

* розрахунок спалених калорій під час тренування;
* аналіз набору вправ;
* надання рекомендацій щодо фізичного навантаження.

## Реалізовані принципи ООП

### Абстракція

Абстрактний клас Exercise.

### Наслідування

Класи CardioExercise та StrengthExercise успадковують Exercise.

### Поліморфізм

Метод calories_burned() перевизначається у дочірніх класах.

### Інкапсуляція

Workout використовує приватний список __exercises.

## Інструмент агента

calculate_workout()

Приймає список вправ та повертає:

* список вправ;
* витрачені калорії;
* загальну кількість калорій.

## Запуск

```bash
adk run
```

або

```bash
adk web
```
